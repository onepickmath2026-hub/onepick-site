[카드 1] 표지 (파란 배경, 유리 질감)
- 좌상단: 원픽학원 (4자) ※ 고정, 바꾸지 않음
- 우상단 분류: 공부법 : 복습타이밍 (11자, 띄어쓰기 포함) → "분류 : 주제" 형태 유지
- 질문 1줄: 질문은 많이 하는데, (11자)
- 질문 2줄: 왜 성적은 그대로 일까요? (14자)
- 메인 제목(흰색 큰 글씨): 오답 활용방법 (7자)
- 부제(노란 글씨): 복습, 딱 5번만 (9자)
- 하단 흐름: 당일 → 과제 → 주말 → 2주후 → 내것으로 (단계 5개, "→"로 연결)

[교체 규칙]
- "원픽학원"은 항상 그대로 둔다.
- 질문 2줄은 학부모가 속으로 하는 고민을 질문형으로 쓴다(이번 블로그 제목·첫 3줄과 같은 고민).
- 메인 제목은 6~8자, 부제는 7~10자로 짧게 쓴다. 글자가 매우 크므로 넘치지 않게 한다.
- 하단 흐름은 3~5단계, 각 단계 2~4자로 쓴다.
- 부제에 숫자를 쓰면 하단 흐름의 단계 수와 반드시 맞춘다.
- 복습 주기를 쓸 때는 원픽학원 실제 간격(10분 뒤 → 1일 뒤 → 1주 뒤 → 1달 뒤)만 쓴다.
